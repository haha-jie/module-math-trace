# Module Records

Create one Markdown file per analyzed module using `../templates/module-record-template.md`.

Naming:
- Derive a stable lowercase slug from the repository-relative source path and symbol name.
- Use hyphens and add a short path-derived suffix if two modules collide.
- Do not reuse a record for a different symbol just because names match.

For a new conversation, read `../INDEX.md` and the matching module record before repeating analysis.

Update the record after meaningful progress. Preserve old conclusions when correcting them: mark them superseded and explain the evidence for the change.
